HOW TO REPLACE AN IMAGE
=======================

You can replace a placeholder by inserting an image such as:

<img src="../assets/images/your-image.jpg" alt="Description">

For a project-page image, the path starts with ../ because the page is inside
the projects folder.

You can also simply keep the placeholder until you have the final image.

EDITING TEXT
============

Replace those sections with your own writing.

The page structure is intentionally generic so you can add your final:
- project description
- technical explanation
- design decisions
- calculations
- figures
- results
- lessons learned
- additional images
